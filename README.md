# نَسَق — Nasaq

[English](README.en.md) · [دليل الاستخدام](docs/USAGE_AR.md) · [الحالة والقيود](docs/RELEASE_STATUS.md) · [MIT](LICENSE)

نَسَق واجهة عربية وإنجليزية لتنسيق تطوير الويب داخل وكيل برمجة: يجمع المتطلبات، ينظم الاختيارات والموافقات، ويحفظ التقدم، ويعيد استخدام مصادر متخصصة بدل إعادة بنائها.

**نسخة تجريبية عامة قابلة للفحص والاستخدام بمساعدة الوكيل، وليست منظومة مستقلة تضمن بناء أي تطبيق.** المضيف الأولي Codex. المكتبة والاختبارات مفتوحة المصدر؛ تشغيل النماذج أو الخدمات الخارجية قد يحتاج حسابًا وتكلفة منفصلة.

## ابدأ

1. حمّل `skill.zip` من [الإصدارات](https://github.com/y9090oussefwork/NASAQ_All_In_One/releases).
2. فك الضغط. ضع مجلد `nasaq` كاملًا داخل `.agents/skills/` في جذر مشروعك، بحيث يصبح المسار `.agents/skills/nasaq/SKILL.md`. لا تستبدل نسخة معدلة موجودة؛ اطلب معاينة التحديث أولًا.
3. افتح المشروع في جلسة Codex جديدة واختر مهارة `nasaq` إن ظهرت، أو اكتب:

> نسق، ابدأ مشروع ويب لحجز المواعيد. اجمع المتطلبات أولًا، واعرض ملخصًا واختيارات للمصادر. لا تنزّل ولا تنفذ قبل موافقتي.

للاستئناف: «نسق، أكمل من الحالة المحفوظة وراجع ما تغيّر». للإنجليزية: `Nasaq, use English and inspect this existing web project without making changes.`

لا تحتاج حفظ أوامر الأدوات الفرعية. الوكيل يقرأ تعليمات المهارة ويستعمل مدخلها الداخلي. لو لم تظهر المهارة، تحقق من المسار وأعد فتح الجلسة؛ قراءة الملف يدويًا بديل تشخيصي وليست إثبات اكتشاف تلقائي.

## المتاح الآن

- محادثة عربية/إنجليزية، متطلبات واختيار مصادر وموافقات وحدود تنفيذ.
- حفظ حالة، استئناف، كشف تغير المخرجات، ومعاينة تثبيت وتحديث وإزالة على مستوى المشروع.
- تخطيط Spec Kit بطريقة `workflow-reference`؛ يحتاج جلب النسخة المحددة ومراجعتها وإعدادها بإذن المستخدم.
- مسارات محدودة لتشغيل Django وBandit، وتسليم تعليمات تصميم/React للمضيف، مع توثيق مصدر المخرجات.
- اختبارات محلية وبيئات قبول سابقة للواجهة والخادم والبيانات؛ هذه ليست مولدًا عامًا لأي مشروع.

**الحدود:** اختبار Codex السابق وجّه الوكيل صراحة إلى ملف المهارة ثم استأنف المحادثة؛ لا يثبت الاكتشاف التلقائي أو استئناف تنفيذ مشروع كامل داخل المضيف. قبول P10 البشري والمقارنة المقاسة غير مكتملين. Claude Code وCursor مؤجلان. لا تشمل النسخة Android أو سطح المكتب.

## للمساهمين

Python 3.11+ وGit للنواة؛ اختُبرت محليًا على Windows/Python 3.12. المصادر الخارجية تحتاج اعتماديات منفصلة حسب الاختيار.

```sh
python -m unittest discover -s skills/nasaq/tests -q
python scripts/build_release.py
```

المصدر: `skills/nasaq/`. المواصفة والخطط: `docs/`. `legacy/` و`release/` تاريخيان وليسا النسخة الحالية. ملفات التجارب وقواعد البيانات وبيانات الجلسات لا تُنشر.
