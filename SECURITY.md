# Security

Do not post secrets, private projects or account logs in public issues. Use GitHub private vulnerability reporting if available; otherwise request a private reporting channel without disclosing exploit details publicly.

Nasaq runs under its coding host's permissions. It is not an OS sandbox. Source instructions and approval records do not authenticate a human. Review third-party scripts and pin versions before executing them. Never bypass host protections solely to make a test pass.

This experimental release has no guaranteed response SLA. No security certification is claimed.
