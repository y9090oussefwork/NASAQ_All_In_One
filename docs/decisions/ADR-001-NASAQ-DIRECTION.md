# ADR-001 — قرار اتجاه نَسَق

**معتمد من المستخدم — 2026-10-09.**

النص المرجعي الوحيد، بالعربية والإنجليزية، هو [قرار إعادة الاستخدام والتكامل](../../skills/nasaq/references/product-direction.md). يوضع داخل مصدر المهارة ليظل متاحًا عند توزيعها دون اعتماد على ملفات خارج الحزمة.

يُقرأ هذا القرار مع مواصفة البناء 1.1. يفسر دور النواة الداخلية بوصفها تنسيقًا وتكاملًا، ولا يسمح بإعادة بناء وظائف مصادر مناسبة بلا سبب موثق. لا يوسّع صلاحيات التثبيت أو النشر أو الخدمات.
