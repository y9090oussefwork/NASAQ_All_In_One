# Nasaq — public experimental web skill

See [Arabic usage](../../docs/USAGE_AR.md), [SKILL.md](SKILL.md), and [release status](../../docs/RELEASE_STATUS.md). Install the complete `nasaq` folder at `.agents/skills/nasaq` in a Codex project.

Nasaq coordinates requirements, approvals, state and reusable sources. Spec Kit is currently a `workflow-reference`, not a native integration. Codex skill-file reading and session resume were exercised; automatic discovery and human acceptance remain limited.

Python 3.11+ and Git are needed for core scripts. MIT applies to original Nasaq code; external projects keep their own licenses.
