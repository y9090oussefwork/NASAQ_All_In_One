# نَسَق — حزمة ويب عامة تجريبية

راجع [دليل الاستخدام العربي](../../docs/USAGE_AR.md) و[SKILL.md](SKILL.md). ضع مجلد `nasaq` داخل `.agents/skills/nasaq` في مشروع Codex، ثم ابدأ بطلب جمع المتطلبات قبل أي تنزيل أو تنفيذ.

نَسَق ينسق المتطلبات والموافقات والحالة ويعيد استخدام مصادر مناسبة. تكامل Spec Kit الحالي `workflow-reference`، ولا يعني أن كل مصدر خارجي مثبت أو مختبر. اختبار Codex الفعلي أثبت قراءة المهارة واستئناف الجلسة؛ الاكتشاف التلقائي الكامل وقبول المستخدم البشري ما زالا غير مكتملين.

Python 3.11+ وGit مطلوبان للنواة. رخصة MIT تخص كود نَسَق الأصلي، ولكل مصدر خارجي رخصته.
