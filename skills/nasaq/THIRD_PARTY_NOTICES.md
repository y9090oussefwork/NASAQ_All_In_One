# Third-party sources

This distribution contains original Nasaq instructions, metadata, examples and a local validator. External projects are referenced by URL in assets/providers.json and references/provider-catalog-ar.md. Their complete skills, code, binaries, icons and fonts are not included.

A reference is not a relicense, endorsement, partnership or claim of execution. Review the applicable license at the exact version before copying, adapting, distributing or activating external components. Preserve notices when required. Skill licenses, runtime licenses, IDE plugin terms and hosted-service terms are distinct.

All pin/digest/license-review fields for external activation are intentionally unresolved in the candidate registry. They must be completed from an actual reviewed source before activation. The original build specification is retained as a user-requested, self-authored project document; it is not a copied third-party skill.
