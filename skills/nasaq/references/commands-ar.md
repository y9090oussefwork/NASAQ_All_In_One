## 05. قاموس الأوامر الموحد

هذه **أوامر محادثة مطلوب بناؤها**، وليست أوامر طرفية موجودة الآن. على المنصة التي تدعم استدعاء مهارة أصلية، يمكن توفير اسم تقني مثل `nasaq` بالطريقة التي توثقها المنصة. لا تفترض صلاحية `/نسق` أو نفس صيغة الشرطة المائلة في كل الأدوات. الأسماء العربية واجهة فوق المقاصد التالية.

المتاح حاليًا داخل الوكيل للمشروع الجديد: ابدأ/متطلبات/اقترح/اعتمد/عدل/خطط/حالة/توقف/أكمل/لغة وأوضاع التحكم في التخطيط، عبر [مسار المحادثة](conversation-project.md). بقية الجدول مقاصد عامة وليست وعدًا بمحولات تنفيذ جاهزة. يفهم الوكيل المحادثة ويستدعي المساعد الداخلي؛ لا يوجد محلل أوامر عربية مستقل أو تشغيل خلفي.

| الأمر العربي | المقابل الإنجليزي | المقصد والمخرج | الحد الافتراضي |
|---|---|---|---|
| نسق مساعدة | nasaq help | أقصر طريق للهدف والأوامر المناسبة للحالة | قراءة |
| نسق ابدأ | nasaq start | تحديد جديد/قائم وبدء الاكتشاف المناسب | لا تنفيذ للتطبيق |
| نسق افحص | nasaq audit | تقييم مشروع قائم بالأدلة والمجهول | قراءة فقط |
| نسق خريطة | nasaq map | إنشاء أو تحديث خريطة محددة بمصادرها | معاينة؛ الحفظ بإذن |
| نسق متطلبات | nasaq requirements | استكمال المتطلبات ومعايير القبول | وثائق ضمن التفويض |
| نسق منافسين | nasaq competitors | مقارنة عامة موثقة وفجوات وفرص | بلا حسابات/مسح هجومي |
| نسق اقترح | nasaq recommend | مقارنة تقنيات أو أدوات أو حلول | اقتراح فقط |
| نسق خطط | nasaq plan | خطة معمارية وتنفيذ واختبارات ومخاطر | لا كود منتج |
| نسق صمم | nasaq design | اتجاه بصري وتجربة ومكونات ونموذج | نموذج منفصل قبل الدمج |
| نسق مهام | nasaq tasks | تحويل الخطة المعتمدة لمهام مترابطة | لا تنفيذ |
| نسق جهز | nasaq setup | اقتراح إعداد البيئة والتكاملات | dry-run ثم موافقة |
| نسق نفذ | nasaq implement | تنفيذ المهمة/التغيير المعتمد فقط | مقيد بالخطة والصلاحيات |
| نسق اختبر | nasaq test | بناء/تشغيل خطة اختبارات محددة | لا تثبيت أو ضغط ضمني |
| نسق راجع | nasaq review | مراجعة فرق محدد وجودته ومطابقته | لا إصلاح تلقائي |
| نسق أمان | nasaq security | مراجعة تهديدات وفحوصات مأذونة | لا هجوم على طرف ثالث |
| نسق أداء | nasaq performance | ميزانية وقياس وتحليل اختناقات | لا تحسين واسع ضمني |
| نسق نظف | nasaq cleanup | مرشحات كود ميت/تكرار وخطة حذف | تقرير أولًا |
| نسق أصلح | nasaq fix | تشخيص واختبار يعيد الخطأ ثم إصلاح محدود | لا refactor جانبي |
| نسق وثق | nasaq document | تحديث الوثائق المتأثرة والتحقق من مصادرها | لا توليد حقائق مخترعة |
| نسق حالة | nasaq status | الحالة والموانع والأدلة والقرارات | قراءة |
| نسق اعتمد | nasaq approve | اعتماد قرار/خطة محددة الإصدار والنطاق | لا اعتماد بلا تحديد |
| نسق عدل | nasaq revise | تعديل متطلبات/خطة مع بيان الأثر | إبطال الموافقات المتأثرة |
| نسق أكمل | nasaq resume | فحص آخر حالة وفرق الكود ثم الاستئناف | يعيد فحص الشروط |
| نسق توقف | nasaq pause | وقف منضبط وحفظ تسليم الحالة | حسب قدرات المضيف |
| نسق تراجع | nasaq rollback | اقتراح رجوع محدد قابل للمراجعة | لا reset أو حذف تلقائي |
| نسق سلم | nasaq handoff | تقرير تسليم/حزمة تحقق وتعليمات تشغيل | ليس نشرًا |
| نسق انشر | nasaq release | إعداد إصدار وخطة نشر | تنفيذ النشر بإذن مستقل |
| نسق لغة | nasaq language | تبديل لغة العرض للمستخدم | لا تغيير لغة المنتج |
| نسق إعدادات | nasaq settings | عرض/اقتراح تغيير تفضيلات العمل | الحساسة تحتاج موافقة |
| نسق قدرات | nasaq doctor | تشخيص الأدوات والمنصات والقيود | لا تثبيت أو كتابة خفية |
| نسق أدوات | nasaq tools | الأدوات المختارة وأسبابها وحالتها | لا تنزيل تلقائي |
| نسق حدث | nasaq update | فرق إصدار نَسَق أو أداة وخطة ترحيل | لا تحديث عائم تلقائي |

يقبل `اختبر` نطاقات مثل `الوحدات` و`التكامل` و`الواجهة` و`الأداء` و`التحمل` و`الأمان` أو معرف ميزة. اختيار «كل الاختبارات» يعني كل الاختبارات المناسبة والمأذونة في الخطة، وليس تشغيل الضغط على الإنتاج.

يفصل `راجع` بين مراجعة خطة ومراجعة فرق كود. ويفصل `جهز` بين معاينة تثبيت المهارة وتثبيت تبعيات التطبيق. لو كان النطاق مجهولًا ويغيّر المخاطر، اسأل سؤالًا محددًا بدل التخمين.

الأوامر تنشئ طلبات منظمة تخضع لنفس سياسة الأمان، سواء كتبت بالعربية أو بالإنجليزية. لا تختصر الموافقة على حذف بيانات في عبارة عامة مثل «تمام» ما لم تكن مرتبطة بطلب واحد واضح حاضر في المحادثة.
